# Dynamic Island 0.1.12-dev9 · Local test: a gentler shade return

Based on 0.1.12-dev8. Prepared locally for device testing; not published.

- The pill returns from the notification shade at a more relaxed pace: spring response 0.34 → 0.46 seconds, keeping the damping ratio at 0.72.
- Its existing small overshoot is now visible instead of being clipped at 100%. Opacity and bubble merging remain bounded to 0–1, while body geometry can briefly grow and settle. The content follows the body.
- Touch and status-bar coverage follow the visible pill. Extra growth is constrained at the screen edges.
- These changes target the shade-return transition in #3. The unlock delay and expanded-card spring settings are unchanged in this test build.
- Pixel checks cover 60Hz and 120Hz return timing and overshoot, interruption by reopening the shade, touch/coverage, and a screen-edge position. Device feedback is still needed for the feel.

## 한국어

0.1.12-dev8 기반의 로컬 기기 테스트용 빌드이며 아직 게시하지 않았습니다.

- 알림창을 닫은 뒤 알약이 더 여유 있게 돌아옵니다. 스프링 응답값을 0.34초에서 0.46초로 늘리고 감쇠비는 0.72로 유지합니다.
- 기존의 작은 반동을 100% 크기에서 잘라내지 않고 보여 줍니다. 투명도와 버블 합침은 0~1 범위를 지키고, 몸체와 내용은 잠깐 커졌다가 자리 잡습니다.
- 터치와 상태바 가림 영역도 보이는 알약을 따르며, 화면 가장자리에서는 추가로 잘리지 않게 성장을 제한합니다.
- #3의 알림창 복귀 전환을 대상으로 합니다. 이번 테스트에서는 잠금 해제 지연이나 펼친 카드의 스프링 설정은 바꾸지 않았습니다.
- 60Hz·120Hz의 복귀 타이밍과 반동, 복귀 도중 알림창 다시 열기, 터치·가림 영역, 화면 가장자리 위치를 픽셀 테스트합니다. 실제 느낌은 기기에서 확인해야 합니다.
