# Dynamic Island 0.1.11-dev10 · Test build: Google sports, live cards and blur

**English** · [한국어](#한국어)

A pre-release for testing, on top of 0.1.10. It also carries everything from the test builds 0.1.11-dev5 to dev9.

## What's new

- **Google sports and other app-drawn cards are readable again.** Cards that show an app's own layout (the Google sports cards) have their text colours resolved with a dark theme, like System UI's shade does, and the text colours are now judged by contrast: colours that already stand out on the dark card are kept, only hard-to-read ones (contrast below 4.5:1) are lifted in lightness, with hue and transparency unchanged. The same rule is used for the shade cards.
- **Google sports matches show as separate cards in the shade.** System UI folds live cards into a grey stack when their app also posts a group summary (a "Sports from Google" heading). A group summary that is marked as a live notification is now left out of the shade list, so the matches come out as separate cards. The notification itself is not cancelled. (The idea and the fix come from the author of the original module; dev9's attempt to take the group apart earlier did not work.)
- **Live card layouts are unified.** Progress-style live notifications (ride, delivery, …) now use the same card as the other live cards: app name and time on top, the icon at the right, the bar under the text with its segments and marker. The old layout is kept only for message popups.
- **The blur no longer sticks out of the card corners.** The blur behind a card was built while the card was still opening and kept its early corner radius, so it was squarer than the card. It is now rebuilt once the radius has settled.
- **No more white or missing blur while cards enter and leave** (dev5, dev6): the blur of the other cards no longer drops out for a frame when a card slips into the hole, and a card no longer flashes white when it enters between others.

## Install and notes

- Install over 0.1.10 or an earlier 0.1.11 test build; it is signed with the same key. Restart System UI afterwards.
- Checked only in a headless test and render environment (which has no blur), **not on a real device**. If a card is still hard to read or the corners still look wrong, send a screenshot together with the report of **Tools → Diagnostics**.

## 한국어

0.1.10 위에 얹은 테스트용 프리릴리스입니다. 테스트 빌드 0.1.11-dev5~dev9의 내용도 모두 들어 있습니다.

### 새로운 점

- **구글 스포츠처럼 앱이 직접 그리는 카드의 글자가 다시 잘 보입니다.** 앱 고유 레이아웃을 보여 주는 카드(구글 스포츠)는 알림창처럼 다크 테마로 글자색을 정하고, 글자색은 이제 대비로 판단합니다. 어두운 카드 위에서 이미 잘 보이는 색은 그대로 두고, 읽기 어려운 색(대비 4.5:1 미만)만 색조와 투명도는 유지한 채 밝기만 올립니다. 알림창 카드에도 같은 기준을 씁니다.
- **구글 스포츠 경기가 알림창에서 따로 카드로 나옵니다.** 앱이 그룹 요약("Sports from Google" 제목)을 함께 올리면 시스템 UI가 라이브 카드를 회색 더미로 접어 버립니다. 라이브 알림으로 표시된 그룹 요약은 이제 알림창 목록에서 빼서, 경기가 각각 따로 카드로 나옵니다. 알림 자체를 취소하지는 않습니다. (아이디어와 수정은 원작 모듈 제작자가 알려 주었습니다. dev9에서 묶음을 직접 푸는 시도는 효과가 없었습니다.)
- **라이브 카드의 모양이 통일되었습니다.** 진행형(ProgressStyle) 라이브 알림(택시, 배달 등)도 다른 라이브 카드와 같은 카드를 씁니다: 위에 앱 이름과 시간, 오른쪽에 아이콘, 텍스트 아래에 구간과 마커가 있는 진행바. 예전 모양은 메시지 팝업에만 남았습니다.
- **블러가 카드 모서리 밖으로 튀어나오지 않습니다.** 카드가 아직 열리는 중에 만든 블러가 그때의 모서리 반경을 그대로 가져서 카드보다 각져 보였습니다. 이제 반경이 안정되면 한 번 다시 만듭니다.
- **카드가 들어가고 나갈 때 하얗게 튀거나 블러가 사라지지 않습니다**(dev5, dev6): 다른 카드가 홀에 들어갈 때 나머지 카드의 블러가 한 프레임 사라지던 것과, 카드 사이로 들어올 때 하얗게 번쩍이던 것을 고쳤습니다.

### 설치와 참고

- 0.1.10이나 앞선 0.1.11 테스트 빌드 위에 그대로 설치하세요. 같은 키로 서명되어 있습니다. 설치 후 시스템 UI를 재시작하세요.
- 헤드리스 테스트·렌더 환경(블러가 없습니다)에서만 확인했고 **실제 기기에서는 확인하지 못했습니다.** 카드가 아직 읽기 어렵거나 모서리가 여전히 이상하면 스크린샷과 **도구 → 진단** 리포트를 함께 보내 주세요.
