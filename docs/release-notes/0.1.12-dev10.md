# Dynamic Island 0.1.12-dev10 · Local test: finish the fast-pull exit

Based on the local dev9 test build. Prepared for device testing; not published.

- The island window now uses the status-bar sub-panel layer above the notification shade. Its previous additional-status-bar layer was below the shade: a fast fling could make the shade opaque before the pill finished shrinking, abruptly covering it.
- The window context and reply window use the same window type. The island keeps its existing restricted touch region and non-focusable window flags, and still shrinks into a dot and fades out when the shade opens.
- Keeps dev9's slower return and small bounce. No extra exit delay or full-expansion cutoff is added.
- Automated checks cover an immediate 0 → 1 expansion and repeated fully-expanded callbacks at 60Hz and 120Hz, for both Canvas and surface opacity, plus restoration on closing. The layer regression check fails with the previous window type. Actual One UI compositor ordering and the fast-fling result still need device confirmation.

## 한국어

로컬 dev9 테스트 빌드 기반이며 기기 테스트용으로 준비했습니다. 아직 게시하지 않았습니다.

- 아일랜드 창을 알림창 위의 상태바 서브 패널 층으로 옮겼습니다. 기존 창은 알림창 아래에 있어, 빠르게 내리면 알약이 줄어들기 전에 불투명해진 알림창이 덮어 갑자기 사라질 수 있었습니다.
- 창 컨텍스트와 답장 창에도 같은 창 유형을 적용합니다. 아일랜드의 제한된 터치 영역과 포커스를 가져가지 않는 창 설정을 유지하며, 알림창을 열면 기존처럼 점으로 줄어든 뒤 사라집니다.
- dev9의 느긋한 복귀와 작은 반동을 유지합니다. 사라짐 지연이나 완전히 펼쳐질 때 강제로 숨기는 조건은 추가하지 않았습니다.
- 60Hz·120Hz에서 즉시 0 → 1로 펼쳐지는 입력, 완전 펼침 콜백 반복, 닫은 뒤 복귀를 Canvas·서피스 투명도 양쪽 경로로 검증합니다. 창 층 회귀 검사는 기존 창 유형에서 실패합니다. 실제 One UI의 창 합성과 빠르게 내렸을 때의 결과는 기기에서 확인해야 합니다.
