# Dynamic Island 0.1.15-dev1 · Settings with a live preview

**Development pre-release** · Changes since **0.1.14** · **English** / [한국어](#한국어)

## Appearance, with a live preview

- A real island preview is pinned above **Appearance** (the page header stays above it). It plays sample cards (a sound-mode event, charging, music and the flashlight) with the settings as they are saved right now. Tap it to move to the next sample.
- **Animation, card material, pill outline, event icon size and flashlight controls are One UI radio lists.** Tapping an option selects it at once and the preview plays the sample that shows it best, then holds that sample until you tap the preview. Options are tagged **Default** and **Recommended** (iMotion, frosted glass, automatic outline, expanding beam).
- Card corners, card header, original icon colours and the battery icon change the preview as you switch them; the corner slider updates it while you drag. The preview is about 30% of the screen height (190–340 dp).
- The separate Animation and Card corners pages are now part of Appearance. Colours, ambient glow and position and size remain sub pages.

## Regrouped settings

- **Notification auto-classification** is one page under Notifications & activities: the master switch, each rule with its own switch, the new-rule wizard and the rule tools. The duplicate page under Advanced is gone.
- **App notifications** moved under Notifications & activities. **System events** is grouped into charging, sound and headphones, quick settings and flashlight, and privacy.
- **Camera cutout calibration** is at the bottom of Island position and size. The **microphone waveform input** sits next to the waveform setting, and **Music player in the shade** is under Behavior. Advanced now holds only experimental recovery and diagnostics.
- **Restart System UI** and the **settings language** are at the bottom of the home page.
- Search follows the new layout, and a new test checks that every search result lands on its setting.

## Install and notes

- Install over 0.1.14; it is signed with the same key. Restart System UI afterwards.
- Checked only in a headless test and render environment, **not on a real device**. Settings and their stored values are unchanged; only where they appear moved.

## 한국어

0.1.14 이후 변경사항을 담은 개발 프리릴리스입니다.

### 실시간 미리보기가 있는 모양 설정

- **모양** 페이지 위에 실제 아일랜드 미리보기가 고정됩니다(페이지 헤더는 그 위에 남습니다). 소리 모드 이벤트, 충전, 음악, 손전등 샘플이 지금 저장된 설정으로 재생되고, 탭하면 다음 샘플로 넘어갑니다.
- **애니메이션, 카드 재질, 알약 외곽선, 이벤트 아이콘 크기, 손전등 조작 방식이 One UI 라디오 목록**입니다. 옵션을 누르면 바로 선택되고, 그 설정이 가장 잘 보이는 샘플을 미리보기가 재생한 뒤 미리보기를 탭할 때까지 유지합니다. 옵션에는 **기본값**과 **추천**(iMotion, 프로스티드 글라스, 자동 외곽선, 넓어지는 빛) 태그가 붙습니다.
- 카드 모서리, 카드 헤더, 원래 아이콘 색, 배터리 아이콘은 바꾸는 즉시 미리보기에 반영되고, 모서리 슬라이더는 드래그하는 동안에도 따라갑니다. 미리보기는 화면 높이의 약 30%입니다(190–340dp).
- 따로 있던 애니메이션 페이지와 카드 모서리 페이지는 모양 페이지 안으로 들어왔습니다. 색상, 외곽 글로우, 위치·크기는 하위 페이지로 남습니다.

### 설정 재배치

- **알림 자동 분류**는 알림·활동 아래 한 페이지입니다: 마스터 스위치, 규칙별 스위치, 새 규칙 마법사, 규칙 도구. 고급 아래의 중복 페이지는 없어졌습니다.
- **앱별 알림**은 알림·활동 안으로 옮겼습니다. **시스템 이벤트**는 충전, 소리와 이어폰, 빠른 설정과 손전등, 개인정보로 나눴습니다.
- **카메라 컷아웃 보정**은 아일랜드 위치와 크기 맨 아래로, **마이크 파형 입력**은 파형 설정 옆으로, **알림창 음악 플레이어**는 동작으로 옮겼습니다. 고급에는 실험적 복구와 진단만 남습니다.
- **시스템 UI 재시작**과 **설정 언어**는 홈 화면 맨 아래에 있습니다.
- 검색은 새 구성을 따르고, 모든 검색 결과가 실제 설정에 도착하는지 확인하는 테스트를 추가했습니다.

### 설치와 참고

- 0.1.14 위에 그대로 설치하세요. 같은 키로 서명되어 있습니다. 설치 후 시스템 UI를 재시작하세요.
- 헤드리스 테스트·렌더 환경에서만 확인했고 **실제 기기에서는 확인하지 못했습니다.** 설정 항목과 저장된 값은 그대로이고, 보이는 위치만 옮겼습니다.
