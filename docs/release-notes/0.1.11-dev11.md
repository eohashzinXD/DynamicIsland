# Dynamic Island 0.1.11-dev11 · Test build: status bar icons after the shade closes

**English** · [한국어](#한국어)

A pre-release for testing, on top of 0.1.10. It also carries everything from the test builds 0.1.11-dev5 to dev10 (readable Google sports cards, the Google sports group no longer stacked in the shade, unified live cards, blur fixes).

## What's new

- **Status bar icons come back sooner when the shade is closed again** (attempt, not confirmed). The island no longer takes over icons that it did not hide itself: System UI fades the icons with the shade, and the island's own fade used to run against that animation. A hook that skipped repeated frame-rate requests of System UI's views is removed too, in case the display stayed at a low refresh rate for a moment after the shade had closed.

## Install and notes

- Install over 0.1.10 or an earlier 0.1.11 test build; it is signed with the same key. Restart System UI afterwards.
- Checked only in a headless test and render environment, **not on a real device**; the cause of the late icons was not pinned down, so this may not fix it. If the icons still appear late, send a screen recording together with the report of **Tools → Diagnostics**.

## 한국어

0.1.10 위에 얹은 테스트용 프리릴리스입니다. 테스트 빌드 0.1.11-dev5~dev10의 내용(읽기 쉬운 구글 스포츠 카드, 알림창에서 쌓이지 않는 구글 스포츠 묶음, 통일된 라이브 카드, 블러 수정)도 모두 들어 있습니다.

### 새로운 점

- **알림창을 다시 닫을 때 상태바 아이콘이 더 빨리 돌아옵니다**(시도한 수정이며 아직 확인되지 않았습니다). 아일랜드가 직접 숨기지 않은 아이콘은 더 이상 건드리지 않습니다. 시스템 UI가 알림창과 함께 아이콘을 흐리게 하는데, 아일랜드의 페이드가 그 애니메이션과 부딪치고 있었습니다. 알림창이 닫힌 직후 화면 주사율이 잠깐 낮게 남았을 가능성에 대비해, 시스템 UI 뷰의 반복된 프레임레이트 요청을 건너뛰던 훅도 뺐습니다.

### 설치와 참고

- 0.1.10이나 앞선 0.1.11 테스트 빌드 위에 그대로 설치하세요. 같은 키로 서명되어 있습니다. 설치 후 시스템 UI를 재시작하세요.
- 헤드리스 테스트·렌더 환경에서만 확인했고 **실제 기기에서는 확인하지 못했습니다.** 아이콘이 늦게 나오는 원인을 정확히 찾지 못해서 이 수정으로 안 고쳐질 수도 있습니다. 아이콘이 여전히 늦게 나오면 화면 녹화와 **도구 → 진단** 리포트를 함께 보내 주세요.
