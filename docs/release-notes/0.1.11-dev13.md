# Dynamic Island 0.1.11-dev13 · Test build: flashlight on more phones

**English** · [한국어](#한국어)

A pre-release for testing, on top of 0.1.10. It also carries everything from the test builds 0.1.11-dev5 to dev12 (readable Google sports cards, the Google sports group no longer stacked in the shade, unified live cards, blur fixes).

## What's new

- **A phone whose flashlight has a single brightness level gets the card too** (from a reporter's own fix). The card shows *On* and a *Turn off* button instead of the slider, so the flashlight is on the island on every phone. A new switch, *Flashlight card* (on by default), turns the card off; the plain popup is used then.
- **The flashlight card is found on more phones.** The card looked only at one camera and gave up completely when any camera of the phone could not be read. Now every camera with a flash is looked at, one that cannot be read is skipped, and the card follows whichever camera's torch is switched on (the flashlight counts as on while any is), with the brightness slider and the *Turn off* button. Phones whose System UI does not post a live notification for the flashlight get the card as well, since the torch is read from the camera itself.
- **No double flashlight.** System UI's own flashlight notification is now recognised on other builds of System UI too (by its tag or title), so it no longer shows next to the card, also when *All notifications in the island* is on.

## Install and notes

- Install over 0.1.10 or an earlier 0.1.11 test build; it is signed with the same key. Restart System UI afterwards.
- Checked only in a headless test and render environment, **not on a real device**; I could not try it on a phone whose flashlight was not recognised, so this may not fix it. If the card still does not show, or shows twice, send a screen recording together with the report of **Tools → Diagnostics**.

## 한국어

0.1.10 위에 얹은 테스트용 프리릴리스입니다. 테스트 빌드 0.1.11-dev5~dev12의 내용(읽기 쉬운 구글 스포츠 카드, 알림창에서 쌓이지 않는 구글 스포츠 묶음, 통일된 라이브 카드, 블러 수정)도 모두 들어 있습니다.

### 새로운 점

- **손전등의 밝기 단계가 하나뿐인 폰에서도 카드가 나옵니다**(제보하신 분이 직접 고친 내용입니다). 슬라이더 대신 *켜짐*과 *끄기* 버튼이 있는 카드가 나와서, 모든 폰에서 손전등이 아일랜드에 보입니다. 새 스위치 *손전등 카드*(기본 켜짐)로 카드를 끌 수 있고, 끄면 짧은 팝업이 대신 나옵니다.
- **손전등 카드가 더 많은 폰에서 나옵니다.** 예전에는 카메라 하나만 보다가, 폰의 카메라 중 하나라도 읽지 못하면 아예 포기했습니다. 이제 플래시가 있는 카메라를 전부 보고, 읽을 수 없는 카메라는 건너뛰고, 켜진 손전등이 있는 카메라를 따라갑니다(어느 카메라든 켜져 있으면 손전등이 켜진 것으로 봅니다). 밝기 슬라이더와 *끄기* 버튼도 그대로 나옵니다. 손전등에 대한 라이브 알림을 시스템이 올리지 않는 폰도 카메라에서 직접 읽으므로 카드가 나옵니다.
- **손전등이 두 번 나오지 않습니다.** 시스템 UI의 손전등 알림을 다른 빌드에서도(태그나 제목으로) 알아보고 카드 옆에 같이 나오지 않게 했습니다. *모든 알림을 아일랜드로*가 켜져 있어도 마찬가지입니다.

### 설치와 참고

- 0.1.10이나 앞선 0.1.11 테스트 빌드 위에 그대로 설치하세요. 같은 키로 서명되어 있습니다. 설치 후 시스템 UI를 재시작하세요.
- 헤드리스 테스트·렌더 환경에서만 확인했고 **실제 기기에서는 확인하지 못했습니다.** 손전등이 인식되지 않던 폰에서 직접 시험해 보지 못해서 이 수정으로 안 고쳐질 수도 있습니다. 카드가 여전히 안 나오거나 두 번 나오면 화면 녹화와 **도구 → 진단** 리포트를 함께 보내 주세요.
